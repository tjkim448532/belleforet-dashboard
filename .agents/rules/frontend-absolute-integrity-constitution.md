# 📜 [벨포레 프론트엔드 데이터 절대 무결성 헌법]
### — 가짜 숫자·추론 로직 완전 박멸을 위한 단일 최고 명령 (SSOT)

---

### 제1조 [가짜의 절대적 정의]
> **"백엔드(API) 응답 원본에 명시되지 않은 모든 것은 가짜다."**
1. 하드코딩된 숫자/단가/비율뿐만 아니라, 프론트엔드가 자체적으로 수행한 **모든 사칙연산, 역산, 안분, 가중평균, 정규식/문자열 추론(`.includes`)은 예외 없이 전부 '가짜'**로 규정한다.
2. 프론트엔드는 백엔드 데이터를 있는 그대로 비추는 **'투명한 거울'**이어야 하며, 어떠한 창작도 허용되지 않는다.

---

### 제2조 [기능 파괴 우선 원칙 (Fail-Stop Principle)]
> **"화면이 깨지는 것이, 가짜 숫자로 메우는 것보다 천 배 낫다."**
1. 백엔드에서 내려주지 않는 지표가 있다면 컴포넌트가 빈칸(`-`)이 되거나 에러가 발생하더라도 **절대 임의의 계산식이나 더미 폴백으로 메우지 마라.**
2. 기존에 동작하던 코드나 레거시 페이지라 할지라도, 백엔드 SSOT와 연결되지 않는 가짜 로직이라면 **동작 여부와 무관하게 즉각 도려내고 삭제**하라.

---

### 제3조 [전역 전수 조사 강제 (No Blind Spots)]
> **"지시받은 화면만 보지 마라. `src/` 폴더 내 모든 파일이 감사 대상이다."**
1. 사용자가 언급한 특정 화면에 시야를 가두지 마라.
2. `src/` 내의 **모든 관리자 페이지, 시드(Seed) 데이터, 공통 변환기(Transformers), 전역 컨텍스트(Context), 훅(Hooks), 라우트(Routes)**까지 예외 없이 전수 스캔하라.

---

### 제4조 [의미론적 심층 역추적 (Semantic Forensic)]
> **"단순 텍스트 검색에 숨지 마라. 데이터의 족보를 끝까지 추적하라."**
1. 단순 린터(Linter)나 정규식 검색으로 검사를 끝냈다고 보고하지 마라.
2. 화면에 찍히는 모든 숫자에 대해 **`화면 렌더링 ➔ 상태 변수 ➔ 데이터 변환 함수 ➔ API 응답 필드`**로 이어지는 데이터 흐름을 1줄씩 역추적하여, 중간에 사람의 손이나 연산식이 개입된 흔적을 전부 적발하라.

---

### 제5조 [입증 책임 (Burden of Proof)]
> **"모든 숫자는 백엔드 출처(Field)를 스스로 증명해야 한다."**
1. 화면에 표시되는 모든 숫자와 지표는 "백엔드 어떤 API의 어떤 필드(`key`)에서 유래했는가"를 1:1로 증명할 수 있어야 한다.
2. 출처를 1:1로 증명하지 못하는 모든 변수와 계산식은 즉시 유죄로 추정하고 폐기하라.
