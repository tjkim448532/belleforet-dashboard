## 1. 현상 요약 (Problem Statement)

대시보드 **[회원 이용 실적 및 연간 방문 추적]** 화면에서 기간을 변경하여 조회할 때:
- **`2026-06-01 ~ 2026-06-30` (6월 당월)**: 회원수 **12명**, 총 이용액 **₩1,118,500원**
- **`2026-01-01 ~ 2026-06-30` (상반기 6개월)**: 회원수 **12명**, 총 이용액 **₩1,118,500원**

기간을 1개월에서 6개월로 대폭 늘렸음에도 불구하고 **회원수, 이용액, 1위 VIP, LTV 등 모든 지표가 1원 1명도 변하지 않고 6월 수치와 100% 동일하게 고정되는 현상**이 발생하고 있습니다.

## 2. 프로덕션 DB 전수 실측 원인 분석 (Root Cause Analysis)

### 2.1. 2026년 1월 ~ 5월 회원 원천 데이터 전무 (0건)
프로덕션 DB를 월별로 직접 전수 실측 쿼리한 결과, 원천 테이블의 수집 일자가 **2026년 7월부터 시작**된 것으로 확인되었습니다.

### 2.2. 매출 마트와의 데이터 비대칭 (Data Discrepancy)
- 전사 매출 마트(`mat_v6_data_mart_revenue`)에는 2026년 1월 ~ 5월 골프 매출 **약 25.5억 원**, 객실 매출 **수십억 원**이 정상 집계되어 있습니다.
- 그러나 회원 단위의 개별 내장객 및 투숙객 원천 파일(`archive/originals/`)이 7월 이전 구간에 대해 S3에 적재되지 않았거나, RDS Raw 테이블로 인제스천(Ingestion) 배치가 누락되었습니다.
- 6월의 12명은 7월 4일자 덤프 파일(`archive/originals/2026-07-04/골프-내장객.csv`)에 우연히 포함되어 있던 6월 말 며칠치 잔여 레코드(57건)에 불과합니다.

### 2.3. 결론
1월~5월의 골프 및 객실 회원 방문객 데이터가 `0명`이므로, `1월~6월 상반기`를 조회해도 `0 + 0 + 0 + 0 + 0 + 12 = 12명`으로 계산되어 **6월 수치와 동일하게 멈춰 있는 것**입니다. (7~9월 데이터를 포함하여 조회하면 400~600명으로 정상 증가함 확인 완료)

## 3. 백엔드 데이터 엔지니어링 작업 요청 사항 (Action Items)

### 3.1. [필수 1] 2026년 1월 ~ 6월 원천 CSV 덤프 S3 업로드 및 Raw 테이블 소급 적재 (Backfill)
- **기간**: `2026-01-01` ~ `2026-06-30`
- **대상 원천 파일 및 적재 대상 테이블**:
  1. `골프-내장객.csv` ➔ `raw_골프_내장객_v6`
  2. `골프-예약.csv` ➔ `raw_골프_예약_v6`
  3. `골프-정산.csv` ➔ `raw_골프_정산_v6`
  4. `객실-예약.csv` ➔ `raw_객실_예약_v6`
  5. `객실-정산.csv` ➔ `raw_객실_정산_v6`

### 3.2. [필수 2] 골프 내장객 일자 필터링 기준 보정 (`route.ts`)
- 현재 쿼리는 `SUBSTRING(p.등록일시, 1, 10)`을 기준으로 일자 필터를 걸고 있습니다.
- 사전 예약 시 `등록일시`는 실제 라운딩(내장) 일자보다 며칠 또는 몇 주 전일 수 있습니다.
- 내장객 테이블의 실제 내장(이용) 일자 컬럼 또는 `raw_골프_예약_v6.영업일자`를 조인하여 **실제 라운딩 일자 기준**으로 조회되도록 정규화해 주십시오.

### 3.3. [필수 3] 백필 완료 후 디둡(Deduplication) 및 정산 집계 검증
- 배치 백필 시 중복 행이 발생하지 않도록 `ROW_NUMBER() OVER(PARTITION BY 예약번호_K, 동반객순번_K ORDER BY 수정일시 DESC, raw_id DESC)` 디둡 로직이 온전히 작동하는지 확인.
- 정산 테이블과의 조인 시 `SUM(매출)`이 1:1로 유실 없이 매칭되는지 확인.

## 4. 백필 완료 후 검증 기준치 (Acceptance Criteria)

백필 완료 후 `GET /api/v6/report/daily-member-visitors?startDate=2026-01-01&endDate=2026-06-30` 호출 시:

1. **기간 이용 회원수 (`summary.totalVisitors`)**:
   - 기존: 12명 (결측 상태)
   - 기대치: **수백 명 단위의 상반기 실제 골프/객실 회원수 정상 복구**
2. **기간 회원 총 이용액 (`summary.totalSpend`)**:
   - 기존: ₩1,118,500원 (결측 상태)
   - 기대치: **상반기 골프/객실 회원 결제 총액(수억~십수억 원) 정상 복구**
3. **올해 회원 누적 LTV (`summary.totalYtdSpend`)**:
   - 상반기 방문 회원들의 2026년 전체 누적 결제액 정상 합산.
4. **올해 최다 방문 VIP (`summary.topLoyalMember`)**:
   - 상반기 다회 방문 골프/콘도 회원이 정상 1위로 집계.
